# 🚀 3X-UI on Railway new panel

پنل **3X-UI** آماده دیپلوی روی **Railway** با Docker.

این پروژه بر اساس فورک شما ساخته شده:
**https://github.com/aavsvs80-coder/3X-ui.3.7.0**

---

## ✨ ویژگی‌ها

- پشتیبانی کامل از نسخه **v3.7.0**
- استفاده از پورت داینامیک Railway (`PORT`)
- قابل تنظیم مسیر دسترسی پنل (`/panel/` یا `/`)
- ذخیره دائمی دیتابیس با Volume
- سازگار با TCP Proxy برای Reality / gRPC / xHTTP
- پشتیبانی از WebSocket و HTTP Upgrade

---

## 📦 نحوه دیپلوی روی Railway

### ۱. آپلود ریپو در گیت‌هاب

1. این پوشه را به عنوان یک ریپازیتوری جدید در گیت‌هاب خودت بساز.
2. فایل‌ها را آپلود کن (یا از همین ZIP استخراج کن و push بزن).

### ۲. اتصال به Railway

1. وارد [railway.app](https://railway.app) شو و لاگین کن.
2. روی **New Project** کلیک کن.
3. گزینه **Deploy from GitHub repo** را انتخاب کن.
4. ریپازیتوری این پروژه را انتخاب کن.
5. Railway به صورت خودکار از روی `Dockerfile` بیلد و دیپلوی می‌کند.

### ۳. تنظیم Volume (خیلی مهم)

برای اینکه دیتابیس و تنظیمات بعد از ری‌استارت پاک نشوند:

1. وارد سرویس خودت در Railway شو.
2. به بخش **Settings → Volumes** برو.
3. یک Volume جدید بساز و مسیر آن را روی `/etc/x-ui` تنظیم کن.

### ۴. متغیرهای محیطی (اختیاری)

در بخش **Variables** می‌توانی این‌ها را اضافه کنی:

| متغیر | توضیح | پیش‌فرض |
|-------|-------|---------|
| `PORT` | پورت پنل (Railway خودش مقدار می‌دهد) | `2053` |
| `XUI_INIT_WEB_BASE_PATH` | مسیر دسترسی به پنل | `/` |

مثال مسیر امن‌تر:

```
XUI_INIT_WEB_BASE_PATH=/panel/
```

## 🔑 ورود به پنل

بعد از دیپلوی موفق:

```
https://your-app.up.railway.app/
```

یا اگر مسیر را تغییر دادی:

```
https://your-app.up.railway.app/panel/
```

**نام کاربری پیش‌فرض:** `admin`  
**رمز عبور پیش‌فرض:** `admin`

> ⚠️ بعد از اولین ورود حتماً نام کاربری و رمز را تغییر بده.

## 🔌 استفاده از TCP Proxy (برای Reality / gRPC)

1. در Railway برو به **Settings → Networking**.
2. روی **Add TCP Proxy** کلیک کن.
3. پورت داخلی را `8080` (یا هر پورتی که در اینباند گذاشتی) تنظیم کن.
4. دامنه و پورت اختصاصی که Railway می‌دهد را در بخش **Host** اینباند پنل وارد کن.

## 🛠️ اگر می‌خواهی از باینری فورک خودت استفاده کنی

1. در ریپوی اصلی‌ات (`aavsvs80-coder/3X-ui.3.7.0`) یک **Release** بساز.
2. فایل `x-ui-linux-amd64.tar.gz` را آپلود کن.
3. در `Dockerfile` این پروژه، لینک Release خودت را چک کن (از قبل آماده است).

اگر Release نداشته باشی، به صورت خودکار از نسخه رسمی `MHSanaei/3x-ui` استفاده می‌کند.

## 📌 نکات مهم

- Railway فقط پورت HTTP/HTTPS را به صورت عمومی باز می‌کند. برای پروتکل‌های مستقیم TCP از **TCP Proxy** استفاده کن.
- حتماً Volume روی `/etc/x-ui` بگذار تا دیتابیس حفظ شود.
- بعد از هر تغییر در کد، کافی است Push کنی تا Railway دوباره بیلد کند.
